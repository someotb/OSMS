# Лабараторная работа №5 (Циклический избыточный код. CRC)
> Выполнил студент группы ИА-331, Любимов Кирилл Алексеевич

## Цель занятия
Получить представление о том, как осуществляется проверка на наличие
ошибок в пакетах с данными в современных системах связи (Error detection)
посредством использования циклического избыточного кода CRC (Cyclic
Redundancy Check).

## Задание для выполнения практической работы
В рамках данной работы студенты должны научиться вычислять CRC-
последовательности, а также на их основании детектировать ошибки.
